# 📊 MongoDB Student Analytics System

## 📌 Overview
This project demonstrates MongoDB database design, querying, and aggregation using a real-world student dataset. It focuses on data modeling, automation using Node.js scripts, and extracting insights from data.

---

## 🚀 Features
- Insert student data using Node.js script
- Perform advanced queries (filtering, sorting, regex)
- Aggregation pipeline for analytics
- Indexing for performance optimization
- Clean project structure for real-world usage

---

## 🛠️ Tech Stack
- MongoDB (Community Server)
- Node.js
- MongoDB Native Driver
- Ubuntu 22.04
